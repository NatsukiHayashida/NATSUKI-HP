## プロジェクト背景

2024年6月、個人的な実験として「SavvyBot」というAIチャットアプリを開発しました。当初はOpenAI GPT-3.5を使ったシンプルなチャットボットでしたが、ユーザーフィードバックと技術進化に合わせて継続的に改善してきました。

### なぜ改善を続けるのか

1. **技術的好奇心**
   - 新しいAIモデル（Claude 3.5、GPT-4o）の実践的な活用
   - ストリーミング応答やマルチモーダルAIの実装経験

2. **ユーザーニーズの変化**
   - より高速で自然な対話体験への期待
   - 用途に応じた柔軟なAIモデル選択

3. **コスト最適化の必要性**
   - 個人プロジェクトとしての持続可能性
   - ユーザー増加に伴うAPI コストの管理

```typescript
// lib/model-selector.ts
export function selectModel(message: string): AIModel {
  const complexity = analyzeComplexity(message)

  if (complexity === 'low') {
    return 'gpt-3.5-turbo' // コスト: $0.001/1K tokens
  }

  if (complexity === 'high' && needsReasoning(message)) {
    return 'claude-3-5-sonnet' // 高度な推論
  }

  return 'gpt-4-turbo' // バランス型
}

function analyzeComplexity(message: string): 'low' | 'medium' | 'high' {
  const wordCount = message.split(' ').length
  const hasCodeRequest = /code|program|script/.test(message)
  const hasAnalysisRequest = /analyze|compare|evaluate/.test(message)

  if (wordCount < 10 && !hasCodeRequest && !hasAnalysisRequest) {
    return 'low'
  }

  if (hasCodeRequest || hasAnalysisRequest) {
    return 'high'
  }

  return 'medium'
}
```

- GPT-3.5: 簡単な質問、速度重視の場合に最適

- Claude 3.5: 長文生成、複雑な推論に強い

**実践的な使い分けルール：**

### 実装内容

#### 1. Supabase Edge Function（Deno）

**アーキテクチャ：**
```typescript
// supabase/functions/savvybot/index.ts
import { serve } from 'https://deno.land/std@0.168.0/http/server.ts'
import { verifyLineSignature } from './lib/line.ts'
import { handleMessage } from './lib/message-handler.ts'

serve(async (req) => {
  // 1. LINE webhook 署名検証
  const signature = req.headers.get('X-Line-Signature')
  const body = await req.text()

  const isValid = await verifyLineSignature(body, signature, channelSecret)
  if (!isValid) {
    return new Response('Forbidden', { status: 403 })
  }

  // 2. メッセージ処理
  const events = JSON.parse(body).events
  for (const event of events) {
    if (event.type === 'message' && event.message.type === 'text') {
      await handleMessage(event)
    }
  }

  return new Response('OK', { status: 200 })
})
```

#### 2. LINE署名検証（セキュリティ）

**HMAC-SHA256 + Constant-time comparison：**

```typescript
// supabase/functions/savvybot/lib/line.ts
export async function verifyLineSignature(
  body: string,
  signature: string,
  channelSecret: string
): Promise<boolean> {
  // 1. HMAC-SHA256 鍵のインポート
  const enc = new TextEncoder()
  const key = await crypto.subtle.importKey(
    'raw',
    enc.encode(channelSecret),
    { name: 'HMAC', hash: 'SHA-256' },
    false,
    ['sign']
  )

  // 2. 署名計算
  const sig = await crypto.subtle.sign('HMAC', key, enc.encode(body))
  const calcB64 = btoa(String.fromCharCode(...new Uint8Array(sig)))

  // 3. Constant-time比較（タイミング攻撃対策）
  if (calcB64.length !== signature.length) return false
  let diff = 0
  for (let i = 0; i < calcB64.length; i++) {
    diff |= calcB64.charCodeAt(i) ^ signature.charCodeAt(i)
  }
  return diff === 0
}
```

**セキュリティ対策：**
- ✅ HMAC-SHA256による署名検証
- ✅ Constant-time比較（タイミング攻撃防止）
- ✅ テキストサニタイゼーション（制御文字除去）
- ✅ 環境変数検証（Zodスキーマ）

### 技術的な挑戦と解決

#### 1. Promise処理の修正

**問題：**
```typescript
// ❌ 誤った Promise チェーン
return cryptoKey.then((k) =>
  crypto.subtle.sign('HMAC', k, data).then((hashBuffer) => {
    return ok(isValid) // Promise<Result> を返していた
  })
)
```

**解決：**
```typescript
// ✅ async/await で明確に
const key = await crypto.subtle.importKey(...)
const sig = await crypto.subtle.sign('HMAC', key, enc.encode(body))
return ok(diff === 0) // Result を直接返す
```
