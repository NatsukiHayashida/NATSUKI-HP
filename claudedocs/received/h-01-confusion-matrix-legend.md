# H-01 評価指標の欠陥 — 凡例

01 → 真陽性（TP） → 実際に不良で、不良として検出された象限。

02 → 偽陰性（FN） → 実際は不良だが、良品として見逃された象限。

03 → 偽陽性（FP） → 実際は良品だが、不良として過検出された象限。

04 → 真陰性（TN） → 実際に良品で、良品として正しく判定された象限。

05 → 旧指標の作用範囲 → 不良判定側の01・03だけを見ており、右列の02・04を評価していなかった。

06 → 全品を不良と判定する極端値 → すべての製品を不良側へ送ることで、旧指標上は検出率100%・見逃しゼロを達成できる状態。

07 → F1 → 真陽性・偽陰性・偽陽性を使い、検出と過検出の釣り合いを評価する指標。

08 → ROC → しきい値を変えながら、真陽性率と偽陽性率の関係を4象限から評価する指標。

09 → AUC → ROCが示す判別性能を、しきい値全体にわたって評価する指標。
