# H-03 ドメインシフト — 凡例

01 → 学習時テスト良品の最大値：0.38 → 学習と同じ条件で撮影した良品が到達した異常スコアの上端。

02 → 学習時に成立していた分離：AUC 0.999 → 同じ撮像条件のテストでは、良品と不良品をほぼ完全に分けられていた状態。

03 → 別セッション良品100枚の最小値：0.5385 → 撮影セッションが変わると、良品群の最小値さえ学習時良品の最大値より右へ移動した。

04 → 両立しない閾値帯 → 閾値を動かすだけでは、元の分離性能と別セッション良品の正しい判定を同時に満たせない範囲。

05 → 撮像条件の固定 → 閾値調整ではなく、入力となる撮像条件そのものを安定させる方向へ切り替えた。
