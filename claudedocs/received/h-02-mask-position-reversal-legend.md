# H-02 マスクをかける場所で結果が逆転する — 凡例

01 → 入力画像 → 検査対象の部品画像と、画像内に残っている欠陥情報。

02 → 入力側マスク → モデルへ渡す前に適用したため、対象外領域と一緒に欠陥情報まで削ったマスク。

03 → 情報が欠けた前処理結果 → 入力側マスクによって、モデルが判断に使うべき欠陥信号が失われた状態。

04 → 異常検知モデル → 前処理後の画像を受け取り、異常マップを生成する共通のモデル。

05 → 欠陥ピークを失った異常マップ → 入力段階で情報が削られたため、欠陥を十分に表現できない推論結果。

06 → 入力側マスクの結果：過検出率72.4% → マスクという打ち手は同じでも、入力側に置くと結果が悪化した。

07 → 欠陥を保持した前処理結果 → 入力画像を先にモデルへ渡すことで、欠陥情報を残した状態。

08 → 推論後マスク → 異常マップが生成された後で、検査対象外の領域だけを判定から除外するマスク。

09 → 推論後マスクの結果：過検出率20.8% → 同じマスクを異常マップ側へ移すことで、欠陥情報を残したまま改善した。
