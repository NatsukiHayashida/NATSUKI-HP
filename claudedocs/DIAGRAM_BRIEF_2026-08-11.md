## 外観検査AI（`content/projects/gaikan-kensa-ai.mdx`）

### 1. 評価指標の欠陥 — 「引き継いだときの状況」

旧指標は「不良品の検出率」だけだったので、**全品を不良と判定すれば100%**になってしまう。
そのため2年分の試行が公正に比較できていたのか、事後に検証すらできなかった。

| 事実 | 値 |
|---|---|
| テストに使った画像 | 461枚（良品283 / 不良178） |
| 実際のモデル | 正しく止めた178 / 見逃し0 / 良品を捨てた125 / 正しく通した158 |
| 全品を不良と判定した場合 | 正しく止めた178 / 見逃し0 / 良品を捨てた283 / 正しく通した0 |
| どちらも旧指標では | 検出率100% |

### 2. マスクをどこに置くか — 「失敗が教えてくれたこと」

入力画像にマスクをかけると悪化し、推論後の異常マップにかけると改善した。
悪化の理由は、外周を塗るマスクが端にあった欠陥まで消し、見逃しゼロを守るために
閾値が下がり、それまで良品と判定できていた製品が不良側に落ちたこと。

| 事実 | 値 |
|---|---|
| マスクなし（ベースライン）の過検出率 | 44.2% |
| 入力画像にマスク | 72.4%（悪化） |
| 推論後の異常マップにマスク | 20.8%（改善） |
| 背景の反応が出ていた場所 | 画像の四隅 |
| 制約 | いずれも見逃しゼロを守った上での比較 |

### 3. ドメインシフト — 「一番大きな壁」

別の日に撮った良品100枚が、全数誤検出になった。

| 事実 | 値 |
|---|---|
| 同じ日の良品 241枚 | 異常スコア 0.243〜0.364 |
| 同じ日の不良品 178枚 | 異常スコア 0.323〜0.865（中央値 0.491） |
| 別の日の良品 100枚 | 異常スコア 0.515〜0.736（中央値 0.623） |
| 閾値 | 0.323（見逃しゼロで決まる） |
| 別の日の良品より低いスコアだった不良品 | 178枚中107枚 |
| 平均輝度 | 学習データ140 に対し、別の日は167 |
| 同じ日のデータだけで測ったAUC | 0.999 |

### 4. 位置ずれのほうが大きい — 「教師ありから、教師なしへ」（優先度低）

| 事実 | 値 |
|---|---|
| 良品同士の平均ピクセル差 | 8.7 |
| 良品と不良品の平均ピクセル差 | 13.2〜14.9 |
| 差の内訳 | 大半は欠陥ではなく位置ずれ |
