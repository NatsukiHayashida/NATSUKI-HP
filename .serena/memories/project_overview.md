# Project Overview

## Purpose
Natsukiの個人ポートフォリオサイト - Next.js 15.5.4ベースのモダンなWebアプリケーション

## Main Features
- ポートフォリオページ（About、Projects、Blog、Contact）
- MDXファイルベースのブログ・プロジェクト管理システム
- EmailJS統合のお問合せフォーム（多層スパム対策、稼働中）
- ダーク/ライトテーマ対応（next-themes、React 19対応済み）
- トップに戻るボタン（ScrollToTop）実装済み
- モバイルファーストレスポンシブデザイン

## Key Characteristics
- 日本語コンテンツ中心のローカライズ
- セキュリティ重視（CSP、スパム対策、入力サニタイゼーション）
- パフォーマンス最適化（静的生成、Server Components）
- アクセシビリティ準拠
